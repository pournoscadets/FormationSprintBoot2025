# FormationSprintBoot2025
Ce projet constitue le support de formation Spring Boot pour la session 2025

# Demarrage 
1) Pour démarrer le projet on pourra jouer la commande suivante:  ```mvn spring-boot:run```  ou ```./mvnw spring-boot:run```depuis la racine du projet

# Hibernate
1) Pour trouver la version d'hibernate embarqué vous pouvez jouer la commande ```mvn dependency:tree``` et rechercher hibernate ou utliser ```mvn dependency:tree | grep 'hibernate' ```
2) La documentation de la version courante se trouve [ici](https://docs.jboss.org/hibernate/orm/6.6/introduction/html_single/Hibernate_Introduction.html)
3) Vous pouvez rechercher les assocations et voir comment ça fonctionne
